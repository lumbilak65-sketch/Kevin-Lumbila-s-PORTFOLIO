# Inbox & Data Broker Cleaner

A personal Python privacy project focused on reducing inbox clutter and helping people manage their exposure on data broker sites.

## Why I started it

I wanted to make it easier to review recurring emails, find unsubscribe options, and organize requests to remove personal information from data broker sites.

## Project goals

- Scan email locally to help identify mailing lists and possible unsubscribe opportunities.
- Make it easier to keep track of data broker removal requests.
- Keep the workflow clear so users can review actions before taking them.

## Privacy approach

The project is designed around local email review. Any unsubscribe or data removal request may require contacting the relevant sender or data broker directly.

## Technologies

- Python
- Email automation
- Privacy-focused tooling
